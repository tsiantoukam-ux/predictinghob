MSc thesis

Prediction of Human Oral Bioavailability Using Machine and Deep Learning and Model Interpretation with SHAP Values

Marina Tsiantouka · MSc Artificial Intelligence, University of Essex

Human oral bioavailability (HOB) is the fraction of an orally administered dose that reaches the systemic circulation unchanged. This project predicts HOB class from molecular structure using Mordred 2D and 3D descriptors, compares tree ensembles with a neural network, and explains the predictions with SHAP values.
